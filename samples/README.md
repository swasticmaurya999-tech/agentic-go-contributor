# Sample outputs

Each subfolder holds a full agent run on a verified issue, with a comparison to the
real accepted PR:

```
samples/<repo>-<issue>/
  patch.diff       # the agent's change
  pr.md            # the agent's generated PR title + body
  run.log          # full transcript (every tool call + result)
  COMPARISON.md    # agent's diff vs the real merged PR, on the 5 evaluation axes
```

These are generated by running, e.g.:

```bash
python -m agent run --issue https://github.com/spf13/cobra/issues/1816
```

(Populated during validation — see the "Validated on" table in the top-level README.)
